## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Compte rendu

À la fin de chaque tâche, TOUT doit être écrit dans inventaire-charte.md : ce qui a été fait, les décisions prises, les problèmes rencontrés, les questions en suspens, et tout ce qui demande un arbitrage. Ne laisse AUCUNE information importante uniquement dans la réponse du terminal : elle sera perdue. Le fichier inventaire-charte.md est le seul canal de communication qui compte. Si tu as une question à poser, écris-la dans ce fichier, dans une section 'Questions en attente de réponse'.
